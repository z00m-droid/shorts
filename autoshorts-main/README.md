# autoshorts ✂️📱

Длинный стрим, подкаст или фильм → вертикальные **шорты 9:16** для TikTok, Reels и YouTube Shorts или **сборка смешных моментов** одним видео.
Сам находит моменты, ставит вебку стримера сверху и игру снизу (или кадрирует по говорящему), рисует субтитры по одному слову.

```bash
python autoshorts.py stream.mp4 -n 10                  # шорты, моменты выбирают агенты
python autoshorts.py "https://vkvideo.ru/video-…" --to 1h -n 5   # по ссылке: скачает только первый час
python autoshorts.py "https://youtube.com/watch?v=…" --cookies-from-browser edge -n 5  # YouTube с cookies Edge
python autoshorts.py stream.mp4 -n 10 --ai             # моменты, темы, подписи и хэштеги — Claude
python autoshorts.py stream.mp4 --bg satisfying        # вебка сверху, «залипалка» снизу
python autoshorts.py stream.mp4 --compile -n 12        # «смешные моменты» одним видео
python autoshorts.py stream.mp4 --funny -n 8           # шорты из самых смешных моментов
python autoshorts.py movie.mp4 --style cinema --look cinema --fx particles --punch   # кино-эдит
```

## Режим «кинул и забыл»
Запустите `watch.bat` (Windows) или `./watch.sh` (Mac/Linux) и кидайте стримы и фильмы в папку `inbox/`.
Каждый файл нарежется сам, когда докачается, в `results/<имя файла>/`. Вместо видео можно положить `.txt` со ссылкой и флагами: `https://vkvideo.ru/video-… --to 1h -n 5`. Флаги передаются дальше: `watch.bat -n 8 --ai`.
То же вручную: `python autoshorts.py --watch inbox -o results -n 8`.

## Что умеет
| | |
|---|---|
| **Ссылки** | VK Видео, YouTube, Twitch, Rutube и всё, что умеет yt-dlp. С `--from`/`--to` из длинного эфира скачивается только нужный кусок, а не все три часа |
| **Агенты для шортов** | кандидаты — интересные (истории, споры, крючки) и смешные/ироничные вместе, в 3 раза больше нужного → точная расшифровка → локальная Qwen3-4B в роли судей **крючок** (цепляет ли первые 3 с), **история** (есть ли развязка), **зритель TikTok** → **редактор** выбирает итог и пишет заголовок-крючок по словам момента |
| **Поиск моментов** | эвристика: крючки в начале фразы, эмоции, всплески громкости, темп речи; моменты по границам фраз; статичная картинка (меню, лобби, AFK) топит оценку |
| **С Claude** (`--ai`) | Claude читает расшифровку целиком, выбирает самостоятельные моменты с панчлайном, пишет заголовок, крючок, подпись и хэштеги → `posts.txt`. Без `--ai` в `posts.txt` только время и заголовок из фразы |
| **Раскладка** | `auto` — квадрат 1:1 по центру на размытой подложке 9:16 с динамическим кадрированием. `split` — отдельный режим стримера: вебка сверху, игра снизу. `face` и `fit` доступны отдельно. В `auto` лица в игровом кадре не считаются доказательством наличия вебки.
| **Фильмы** | находит монтажные склейки и на каждой переводит кадр на говорящего: нейросетевой детектор лиц YuNet (видит повороты и профили) + движение губ |
| **Субтитры** | по одному слову на стыке половин: `stream` (жёлтый), `soft`, `italic`, `bold`/`tilt`/`clean`, `glow`, `cinema`; строчные, без знаков; в паузах — `*СМЕЁТСЯ*`, `*КРИЧИТ*` |
| **Синхронизация** | текст распознаёт whisper `large-v3-turbo` с запасом ±2 с вокруг момента, время каждого слова уточняется wav2vec2 (forced alignment, как в WhisperX); куски речи, пропущенные whisper на шуме, дораспознаются по детектору речи; известные «галлюцинации» на музыке убираются |
| **Смешное** (`--compile`, `--funny`) | 1) кандидаты в 3 раза больше нужного: реакции в речи, ритм «ха-ха» в звуке, пики смеха; 2) каждый кандидат точно распознаётся заново; 3) нейросеть AudioSet (AST) слышит смех, хихиканье, крики и пение; 4) «агенты» — локальная Qwen3-4B в роли трёх судей (**ироник**, **панчлайн**, **зритель TikTok**) голосуют, **редактор** выбирает итог и пишет ироничные подписи. Всё офлайн, без ключей. `--quick` — только эвристика |
| **Сборка** (`--compile`) | моменты 5–25 с склеиваются с белой вспышкой и свушем; `--format horizontal` — 16:9 |
| **Звук** | −14 LUFS (двухпроходная нормализация), плавный конец |
| **Самопроверка** | каждый готовый ролик проверяется: длина, 1080×1920, звук, громкость, чёрный экран, «замёрзшая» картинка; замечания — в консоли и `report.json` |
| **Обложки и посты** | `short_01_cover.jpg` — кадр с лицом покрупнее в паузе между субтитрами + заголовок крупно; в `posts.txt` к каждому ролику заголовок, описание и хэштеги (пишет локальная модель) |

## Установка
Python 3.10+ и **ffmpeg с libass и libx264**:
- Windows: `winget install ffmpeg` (или сборка gyan.dev «full»);
- Mac: `brew install ffmpeg-full` и `export PATH="$(brew --prefix ffmpeg-full)/bin:$PATH"` — обычный `ffmpeg` из Homebrew собран без libass;
- Linux: `apt install ffmpeg`.

```bash
pip install -r requirements.txt
pip install -r requirements-align.txt   # по желанию: точная синхронизация субтитров и детектор смеха (torch + transformers)
pip install -r requirements-funny.txt   # по желанию: судьи смешного — локальная языковая модель (llama-cpp-python)
```
Программа сама проверяет ffmpeg при старте и скажет, чего не хватает.

**Первый запуск скачивает модели (один раз, нужен интернет):** whisper base ~145 МБ, whisper large-v3-turbo ~1.6 ГБ, wav2vec2 ~1.3 ГБ на язык (ru/en; для других языков — запасной способ синхронизации); для смешного — AST ~350 МБ и Qwen3-4B ~2.5 ГБ (свой файл GGUF: переменная `AUTOSHORTS_LLM`). Дальше всё работает офлайн, кроме `--ai`.

Для `--ai`: ключ Claude API в переменной `ANTHROPIC_API_KEY` (Windows PowerShell: `$env:ANTHROPIC_API_KEY="..."`, bash: `export ANTHROPIC_API_KEY=...`) или `ant auth login`.

## Параметры
| Флаг | По умолчанию | |
|---|---|---|
| `--from` / `--to` | | кусок видео: `90`, `15m`, `1h`, `1:20:00` |
| `--at` | | свои моменты вместо автоподбора: `37:56-38:54,2679-2736` (время в исходнике, края подтянутся к словам) |
| `-o` | out | папка результатов |
| `-n` | 5 | сколько шортов / моментов в сборке |
| `--min` / `--max` | 15 / 60 (со `--compile` 5 / 25) | длина момента, с; агенты подбирают длину по содержанию: шутка — 15–25 с, история — 30–60 с |
| `--lang` | ru | язык речи |
| `--model` | base | whisper для поиска по всему видео (`tiny` быстрее, `small` точнее) |
| `--caption-model` | large-v3-turbo | whisper для субтитров выбранных кусков |
| `--no-align` | | без wav2vec2-синхронизации (быстрее, менее точно) |
| `--device` | cpu | `cuda` — видеокарта NVIDIA (нужны CUDA 12 и cuDNN 9) |
| `--ai`, `--topic` | | моменты и тексты от Claude; тематика канала как подсказка |
| `--layout` | auto | `game`, `split`, `face`, `fit` |
| `--cam` | авто | рамка вебки `x,y,w,h` в пикселях исходника |
| `--cookies-from-browser` | — | браузер для cookies YouTube: `edge`, `chrome`, `firefox` и др.; войдите в YouTube в выбранном браузере |
| `--bg` | игра из стрима | путь к видео или `satisfying` |
| `--style` | stream | `stream`, `soft`, `italic`, `bold`, `tilt`, `clean`, `glow`, `cinema` |
| `--look` | none | цветокор `cinema`, `cold`, `warm` |
| `--fx` | none | `particles` — частицы поверх кадра |
| `--punch` | | удары зумом на громких словах |
| `--compile`, `--format` | | сборка одним видео; `vertical` 9:16 или `horizontal` 16:9 |
| `--funny` | | шорты из самых смешных моментов |
| `--quick` | | без агентов: только эвристика (быстрее, хуже) |
| `--title`, `--bar` | | заголовок-крючок первые 3 с / полоска прогресса |

На выходе в папке `-o`: `short_01.mp4 …` и обложки `short_01_cover.jpg …` (или `compilation.mp4` + обложка), `posts.txt` — готовые подписи для публикации, `report.json` — тайминги, оценки судей и почему выбран момент, итоги проверки.
Расшифровка кэшируется в той же папке отдельно для каждого видео, языка и модели — повторный запуск не распознаёт заново.

## Скорость (замер, 4 ядра CPU без видеокарты)
Стрим 2 ч 49 мин: распознавание `base` — 47 мин, движение в кадре — 3 мин; каждый шорт — 2–3 мин (точное распознавание куска + синхронизация + рендер). С `--device cuda` распознавание в разы быстрее.

## Проверка агентом Claude Code
В `.claude/agents/irony-judge.md` — агент-редактор: открывает `report.json`, оценивает каждый момент 0–10 по критериям иронии и реакции, предлагает что выкинуть, порядок и подписи. В Claude Code: «проверь results/stream агентом irony-judge».

## Ограничения
- Без `--ai` и без судей (`--quick` или нет llama-cpp-python) моменты выбираются по словам, эмоциям, громкости и движению, а не по смыслу — бывают «пустые» куски.
- Судьи — небольшая модель 4B: тонкую иронию понимает не всегда, расшифровка шумного стрима тоже с ошибками. Отбор смешного добавляет ~10–15 мин на 4 ядрах.
- Говорящего в фильме определяем по движению губ — в сценах, где говорят за кадром, кадр остаётся на видимом лице.
- Субтитры по одному слову; ошибки распознавания на очень шумном звуке возможны.


### Игровое кадрирование (`--layout auto` или `--layout game`)

Для горизонтальных игровых записей режим `auto` использует квадратную область 1:1
поверх размытой копии исходного видео (итоговый кадр остаётся 9:16). Положение
квадратной области автоматически и плавно смещается к участкам заметного движения
в кадре. Это визуальная эвристика по межкадровым изменениям, а не распознавание
смысла игрового события; если движение распределено по всему экрану, кадр остаётся
ближе к центру.

Старые раскладки сохранены: `--layout split`, `--layout face` и `--layout fit`.

### YouTube и cookies

Если YouTube отвечает `Sign in to confirm you’re not a bot`, запустите программу с `--cookies-from-browser edge` (или `chrome`/`firefox`). Cookies считываются yt-dlp из локального браузера и не записываются в конфигурацию AutoShorts.

### Стримеры

Чтобы использовать исходную раскладку вебка+игра, укажите `--layout split`. В `auto` программа намеренно не принимает случайно найденное лицо за веб-камеру: это предотвращает ложные срабатывания на игровых персонажах и элементах игры.


## AutoShorts Studio (локальный сайт)

После установки зависимостей и создания `.venv` запустите `start_webui.bat`. Откроется `http://127.0.0.1:8765`.

В интерфейсе можно перетащить видео, выбрать файлы/папку, указать существующий путь к папке с видео или вставить ссылку. Выберите режим «Игра» либо «Игра + стример», число клипов, стиль субтитров и папку результата. Обработка выполняется локально; окно сайта показывает журнал и прогресс по файлам.

Для YouTube, если Edge не позволяет прочитать базу cookies, можно закрыть браузер полностью или экспортировать cookies в Netscape `cookies.txt` и указать путь к файлу. Такой файл содержит авторизационные данные — храните его приватно и удалите после использования. В командной строке доступен параметр `--cookies-file путькфайлу`.

### Что улучшено в этой сборке
- Игровая композиция остаётся квадратной 1:1 на размытой подложке 9:16.
- Добавлено консервативное обнаружение постоянных чёрных полей по краям исходника.
- Трекер учитывает несколько активных областей, сильнее сглаживает движение, ограничивает скорость кадрирования и фиксирует центр при небольшом смещении. Это эвристика движения, а не полноценное распознавание персонажей.
- Пунктуация распознанной речи сохраняется в субтитрах; фразы разбиваются с учётом пунктуации и пауз.
- Режим игры не запускает поиск веб-камеры; поиск вебки включается отдельно в режиме «Игра + стример».

Прямой эфир Twitch в этой версии не захватывается в режиме Live. Для обычных VOD/ссылок используется существующая загрузка через yt-dlp; поддержка прямых эфиров требует отдельной реализации и проверки.

## AutoShorts Studio v4 (локальный веб-интерфейс)

Запуск: `start_webui.bat`. Интерфейс открывается на `http://127.0.0.1:8765`.

- Видео можно перетащить, выбрать файлами или выбрать целую папку через браузер.
- Папка результатов выбирается системным окном «Выбрать папку…».
- Длительность клипа: автоматический диапазон или заданная длина.
- Отбор: умный (полный анализ) или быстрый (эвристический).
- Доступны цветовые профили, динамический зум и заголовок-крючок.
- Для YouTube автоматически проверяются cookies Edge, Chrome, Firefox и Brave, затем выполняется попытка без cookies. Отдельный `cookies.txt` создавать не нужно.
- Для текущих Twitch / YouTube Live включается флажок «Это прямой эфир». Запись идёт до завершения эфира; если платформа не позволяет получить запись с начала, программа пробует начать с текущего момента. После завершения записи начинается обычный анализ и нарезка.

Важно: live-запись и автоматический доступ к YouTube зависят от доступных форматов, авторизации и ограничений самой платформы. Неподдерживаемый эфир или ограниченное YouTube-видео не могут быть гарантированно загружены программой.

### Автоматическое получение ссылок (YouTube / Twitch)

Для URL AutoShorts последовательно проверяет несколько вариантов yt-dlp. Для YouTube используются независимые player-клиенты (default, TV, web_safari, mweb), затем при режиме `--cookies-from-browser auto` проверяются локальные профили Edge, Chrome, Firefox, Brave, Chromium, Opera и Vivaldi. Успешная комбинация повторно используется при скачивании, а не только при получении метаданных.

Если YouTube блокирует гостевой доступ и не принимает локальную сессию, гарантированного обхода нет: часть роликов требует входа, корректных cookies или дополнительных Proof-of-Origin токенов. AutoShorts не обходит DRM, платный доступ, приватность или региональные ограничения. Для обновления загрузчика запустите `update_ytdlp.bat`.

Twitch обычно не требует API-ключа для публичных VOD и публичных live-потоков. Для подписных/ограниченных материалов может потребоваться авторизованная сессия; OAuth-подключение Twitch — отдельная безопасная интеграция, а не универсальный ключ для скачивания любого потока.


## Подключение YouTube в AutoShorts Studio

1. Запусти `setup_youtube_auth.bat` один раз. Он устанавливает PO Token Provider для yt-dlp и собирает локальный компонент BgUtils (требуется Node.js LTS; при наличии winget скрипт попробует установить его автоматически).
2. Запусти `start_webui.bat`.
3. В блоке «Подключение YouTube» нажми «Войти через Google». Откроется отдельный профиль Edge `AutoShorts`; войди в свой Google/YouTube аккаунт.
4. Полностью закрой отдельное окно Edge, затем нажми «Проверить подключение». Это нужно, чтобы yt-dlp мог безопасно прочитать SQLite-базу cookies.
5. После успешной проверки вставляй YouTube-ссылки как обычно. AutoShorts будет использовать отдельный профиль и установленный PO Token Provider.

Пароль и коды подтверждения AutoShorts не получает. Данные сессии хранятся в профиле Edge Windows-пользователя. Не передавай папку профиля и cookies другим людям.

Важно: авторизация и PO Token повышают совместимость, но не гарантируют загрузку любого видео. Возрастные/региональные ограничения, приватность ролика, CAPTCHA, блокировка IP и изменения YouTube могут всё ещё препятствовать доступу.

## YouTube: использовать уже существующий Google-вход

В актуальной сборке AutoShorts не создаёт отдельный профиль браузера. Кнопка «Использовать мой Google-аккаунт» открывает YouTube в обычном браузере Windows. Если пользователь уже вошёл в Google/YouTube, повторная авторизация не нужна. Для скачивания yt-dlp читает cookies из последнего активного профиля Edge, Chrome или Brave (профиль определяется по `Local State`). Если браузер блокирует чтение базы cookies, полностью закройте его и повторите проверку/загрузку.
